# IT Asset Inventory Tracker

## Overview
A browser-based register for IT equipment and its maintenance status.

## Features
Add equipment; assign a user; search the register; change status; delete records.

## How to run
Open `index.html` in a browser. No installation required.

## Technologies
HTML, CSS, JavaScript.
